# 🧑‍🍳 AI Chef — ИИ-шеф-повар

Приложение, которое подбирает рецепты на основе имеющихся у вас продуктов.

## 🚀 Что умеет

- Принимает список продуктов от пользователя
- Ищет подходящие рецепты в базе данных
- Учитывает базовые ингредиенты (соль, сахар, масло и т.д.)
- Показывает состав, инструкцию и ссылку на оригинал

## 🧰 Технологии

| Технология | Назначение |
|------------|------------|
| Python 3 | Язык разработки |
| Streamlit | Веб-интерфейс |
| Pandas | Работа с базой рецептов |
| CSV | Хранение данных |

## 📂 Структура проекта

- `recipe_ai.py` — основной файл приложения (Streamlit)
- `parser.py` — сбор рецептов в базу
- `recipes_database.csv` — база рецептов

## 🚀 Как запустить

1. Установи зависимости:
```bash
pip install streamlit pandas
```
2. Собери базу рецептов (если ещё нет):
```bash
python parser.py
```
3. Запусти приложение:
```bash
streamlit run recipe_ai.py
```
